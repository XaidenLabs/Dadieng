# Submission evidence checklist

- [ ] Public repository URL and immutable release commit
- [ ] Approved license and dependency notices
- [ ] Public npm release-candidate install in a clean external project
- [ ] Monad contract addresses, deployment transactions, and verified source
- [ ] ERC-8004 researcher and validator identities
- [ ] Chainlink CRE simulation/deployment logs and workflow identifier
- [ ] Qwen bounded tool-use trace and published technical article
- [ ] Mera same-passkey fresh-profile decryption recording
- [ ] Envio hosted indexer URL and live GraphQL-driven console metrics
- [ ] Dynamic connect, participant signing, and delegated action recording
- [ ] Two independently controlled validator attestations
- [ ] One hundred replay executions with identical commitments
- [ ] Quarantine and automatic rollback recording
- [ ] Three-minute demo recording and screenshots
- [ ] Reset, degraded-service, and emergency runbooks rehearsed

Unchecked external evidence must be described as pending. Local mocks,
simulations, placeholder addresses, and private preview URLs must never be
presented as sponsor deployment proof.
